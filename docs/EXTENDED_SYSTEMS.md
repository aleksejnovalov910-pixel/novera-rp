# Extended systems

The extended core adds persistent phone contacts/messages, businesses and employees, licenses/fines, vehicle/property keys, character settings/stats, reports/punishments and server-side event rate guards.

Administrative mutations are designed to require an admin level loaded from the account before exposed commands are enabled. Government actions such as issuing fines must also be gated by faction/rank permissions before UI exposure. The services exist first so permission-aware organization workflows can be built without putting financial logic on the client.
