# NOVERA RP — ready-to-play release gate

A build is not called ready until every item below passes on the GTA5HOST runtime.

- [ ] Server boots without fatal package errors
- [ ] New account can register
- [ ] Existing account can log in
- [ ] Three character slots render
- [ ] New character can be created with valid GTA head blend values
- [ ] Age 18–90 is stored
- [ ] Character survives reconnect
- [ ] Character enters dimension 0 / Los Santos
- [ ] HUD renders without giant fallback logo/CEF corruption
- [ ] Cash/bank persist
- [ ] Inventory persists
- [ ] Starter job can be started and paid
- [ ] Vehicle ownership/garage flow works
- [ ] Property baseline works
- [ ] Phone/tablet/settings open
- [ ] No uncaught CEF/native errors during the full path

Only after this gate passes should non-blocking visual polish take priority.
