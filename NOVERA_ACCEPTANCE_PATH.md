# Acceptance path for public alpha

A fresh player must be able to complete this without manual database edits or server restarts:

Register -> login -> choose/create one of 3 characters -> enter Los Santos -> tutorial -> earn money from a starter job -> use an inventory item -> obtain/use a vehicle -> enter/leave property -> reconnect and retain character/economy/inventory/ownership.

Secondary systems must not crash this path. The public alpha is blocked until persistence is verified.
